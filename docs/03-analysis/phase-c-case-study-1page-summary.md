## 핵심 메시지 (BLUF)

> **같은 사안 +6,800만 GO → +4,000만 조건부 GO. Phase C는 의사결정자가 -2,800만의 보이지 않던 위험을 알고 결정하게 합니다. McKinsey 95% 프레임워크 도달.**
