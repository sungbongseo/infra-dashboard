# Phase A+B 종합 경영진 데모 가이드

**대상**: 경영진·영업본부장·재무 의사결정자
**소요**: 약 20-25분 (7 시나리오 × 3분)
**핵심 메시지**: "점추정값 기반 직관적 판단 → 확률·LTV·캐파·탄력성 4차원 통합 의사결정"

## 🎯 메시지 한 줄

> "Phase A+B로 저가수주 판단기가 **단순 손익 계산기**에서 **확률 기반 전략 도구**로 진화했습니다.
> McKinsey 95% 프레임워크 대비 **21.7% → 62%** 달성, 5/6 축이 50%+에 도달."

## 시나리오 1 (3분) — 박리다매 가설 ROL 사례 [전체 흐름 보여주기]

**입력**:
- 품목: Black Top Sheet(2.0mm*10m)_옥천
- 거래처: 주력 거래처 1곳
- 추가수량: 5,500 ROL
- 제안단가: 50,675원 (현행 39,283원 대비 +29% 인상 시나리오)

**시연 포인트**:
1. 3카드 그리드로 단독·풀·포트폴리오 효과 동시 표시
2. **💎 거래처 LTV 효과 카드** (NEW): "수용 시 +800만 보전 / 거절 시 -800만 손실"
3. **💼 PED 자동 적용** (NEW): "PED=-0.8 (R²=0.65, n=14M, 신뢰도 높음)"
4. **🏭 캐파 분석** (NEW): "옥천 공장 87% 사용 — caution"
5. **🎲 Monte Carlo** (NEW): "평균 +6,319만, 95% CI +3,100~+9,500만, 손실확률 18%"

**메시지**: "이 한 화면이 4가지 차원의 판단 근거를 동시에 제공합니다."

---

## 시나리오 2 (3분) — 가짜 확신 제거 (Monte Carlo)

**조작**: MC 토글 OFF → ON

**시연 포인트**:
- OFF: 단일 점추정 +6,319만 (확정인 듯 보임)
- ON: 평균 +6,319만 ± **95% CI 폭 6,400만** + **손실확률 18%**
- "5번 중 1번은 적자날 수 있는 결정" 경각심 환기

**메시지**: "현실은 확률입니다. 평균만 보면 위험을 놓칩니다."

---

## 시나리오 3 (3분) — 캐파 Step-up 숨겨진 비용

**조작**: 추가수량 증가 5,500 → 12,000 ROL

**시연 포인트**:
- 캐파 게이지: 87% → **115%** (severe)
- "🚨 신규 라인 1개 필요. 월 5,000만원 추가 발생" 자동 경고
- "표면 이익 + 6,319만"이지만 실제로는 **-1,300만 적자**

**메시지**: "물량 증산 판정 시 설비투자 변수가 자동 반영됩니다."

---

## 시나리오 4 (3분) — 거래처 LTV 균형추

**조작**: 거래처 변경 (이탈위험 낮음 → 높음)

**시연 포인트**:
- 이탈위험 25/100 거래처: 수용 +200만 (보전 미미)
- 이탈위험 80/100 거래처: 수용 +1,200만 (큰 보전)
- "이탈위험 낮은 거래처는 가격 양보 불필요" 자동 안내

**메시지**: "모든 거래처에 동일 가격 정책은 가치 누수입니다."

---

## 시나리오 5 (3분) — PED 자동 수량 제안

**조작**:
- PED 토글 OFF: 판가 -10% 입력 → 수량 변경 없음 (비현실)
- PED 토글 ON: 판가 -10% → "수량 +12.3% 자동 제안" + 시뮬 결과 즉시 갱신

**시연 포인트**:
- 273개 품목 14개월 실측 데이터로 회귀
- 수동 override 가능 (영업 경험 반영)
- PED -0.5 (비탄력) vs -1.5 (탄력) 차이 시각화

**메시지**: "판가 결정 한 번으로 매출 변화가 즉시 자동 반영됩니다."

---

## 시나리오 6 (3분) — 단위공헌이익 실체

**조작**: 원가 슬라이더 원자재 +50% 시뮬

**시연 포인트**:
- 단위 마진 −12,588원 (적자 표시)
- 그러나 단위 공헌이익 +14,875원 (양수)
- **"박리다매 여지 존재"** 자동 배지
- 추가 5,500 ROL 판매 시 **+8,180만 이익** 자동 계산

**메시지**: "총원가 적자처럼 보이는 품목도 박리다매 여지가 있을 수 있습니다."

**조작**: 5개 신규 영역(MC + 캐파 + LTV + PED + 공헌이익) 모두 활성
