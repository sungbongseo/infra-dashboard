## 1. Root Cause 진단 (실데이터)

### Issue 1: Outlier 마진율

```
극단 outlier Top 5 (실측):
  1. 폴리탑 분말 8.8KG       매출 5만원   적자 -147만   → 마진 -2946%
  2. GFRP BENT BAR 13mm    매출 353만   적자 -3,070만  → 마진  -870%
  3. GFRP BAR 13mm         매출 1,102만 적자 -8,549만  → 마진  -776%
  4. KP-HU550 B부 (1KG)    매출 14,212원 적자 -97,724원 → 마진  -688%

|마진| > 100%: 9건 (전체 879개 중 1.0%)
```

**원인**: 매출 매우 작은 품목 (5만원, 1만 원대)에서 영업이익 큰 적자 → 마진 폭증
**영향**: Y축 자동 → 9000% 표시 → 99% 품목이 한 줄 압축

### Issue 2: 범례 ↔ 차트 dot 불일치

- `QUADRANT_ICONS`: lucide React Star/Shield/AlertTriangle/ShieldAlert
- 차트 Cell: **색상만 다름, 모양은 모두 원**
- 사용자가 범례에서 본 아이콘을 차트에서 못 찾음

### Issue 3: 툴팁 부재

- glossary-profitability.ts에 BCG 0건
- 13 핵심 용어 (사분면 4 + 마진 2 + 옵션 2 + 임계 4 + 개념 1) 정의 없음

### Issue 4: 수치 정확성 검증

- 가중 마진 152,490,409 / 4,246,520,467 = **3.59%** ✅ 정확
- 산술 평균 32.17% — outlier 1건이 +28.6%p 왜곡 ⚠
- 사분면 분포 합 / 매출 합 모두 일치 ✅
- → **계산 정확. 산술 평균 KPI만 사용자 혼란 유발.**

## 2. 변경 사항 (4 sub-step)

### B-Improve-1: Y축 [-50%, 100%] 클램핑

**파일**: `PortfolioMatrixTab.tsx`

```ts
// chartData에 클램핑 + isOutlier 플래그 추가
const Y_MIN = -50;
const Y_MAX = 100;
const chartData = entries.map(e => {
  const isOutlier = e.marginRate > Y_MAX || e.marginRate < Y_MIN;
  return { x: e.sales, y: Math.max(Y_MIN, Math.min(Y_MAX, e.marginRate)),
           yActual: e.marginRate, isOutlier, ... };
});

// YAxis domain={[Y_MIN, Y_MAX]} + label "[-50~100]"
// Tooltip에 yActual + outlier 표시 ("⚠ outlier")
// 차트 하단 outlier 카운트 warning
```

### B-Improve-2: 사분면별 SVG 모양

**파일**: `PortfolioMatrixTab.tsx` Scatter `shape` prop

```tsx
shape={(props) => {
  const q = payload.quadrant;
  if (q === "star") {
    // 5각 별 path (10 vertices, outer=7 inner=3)
    return <polygon points={...} />;
  }
  if (q === "cash_cow") return <circle r={5} />;

}}
```
