### D.2 시연 시퀀스 (Live Demo, 15-20분)

#### Step 1: Setup (2분)
```bash
cd /d/분석/인프라 대시보드
npm run dev
```
- 브라우저 → http://localhost:3000/dashboard/data
- 13개 Excel 파일 drag & drop
- 모든 파일 "ready" 상태 확인

#### Step 2: 시작 화면 (1분)

#### Step 3: 거래처 + 품목 선택 (2분)
- 매출 비중 큰 거래처 선택 (실제 데이터 기반)
- Top 5 품목 중 1건 선정
- 단순 시뮬 결과 — "+X,XXX만 GO 직감 판단"

#### Step 4: 8 토글 시퀀셜 활성 (10-15분)

각 토글 활성 후 1-2분 설명:

```
1. 💼 PED 토글 ON  → "자연 수량 변화 확인"
2. 💎 LTV 카드     → "거래처 가치 +X억"
3. 🎲 Monte Carlo  → "95% CI, 손실확률"
4. 🎯 시장 반응     → "100% 보복 시나리오"
5. 🕒 12개월 시뮬   → "BEP 시점 + NPV"
6. 🔄 카니발       → "포트폴리오 순효과"
   (heatmap 표시 + Top-N 잠식 품목)
7. ⚖️ Capacity    → "캐파 게이지"
```

#### Step 5: 마무리 (1분)
- "+X,XXX만 → +Y,YYY만 조건부 GO" 비교
- "이것이 같은 결정자가 알고 결정 vs 모르고 결정의 차이"

| 노트북 OS 갱신/재시작 | 시연 전 1시간 노트북 재시작 + 환경 사전 확인 |
| Excel 파일 업로드 실패 | IndexedDB 사전 캐시 (이전 세션에서 한 번 업로드 완료) |
| 데이터 토글 활성 안 됨 | 사전 dry-run 확인 + 백업 PPTX 즉시 전환 |
| 화면 해상도 깨짐 | 16:9 widescreen 모드 사전 확인 |
| 인터넷 연결 끊김 | 로컬 dev 서버이므로 무관, 단 첫 빌드는 사전 완료 |
| 시연 직전 코드 변경 | **D-1 이후 코드 변경 금지** — 변경 시 빌드 재실행 + 회귀 테스트 |

### D.4 PPTX vs Live Demo 결정 기준

| 청중 | 권장 |
|---|---|
| 경영진 (CEO, COO) | PPTX (압축적, 메시지 명확) |
| 영업본부장 + 영업담당 | Live Demo (실용성, 즉시 적용 가능) |
| 재무 + 전략 의사결정자 | PPTX → Q&A에서 Live Demo 전환 |
| 외부 (이사회, 투자자) | PPTX (보안, illustrative case) |
