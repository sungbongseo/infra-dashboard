## SECTION C. KPT 회고 (D+2 ~ D+3)

피드백 + 자체 회고를 종합한 구조화된 KPT (Keep / Problem / Try).

### C.1 KEEP — 잘 작동한 자산 (재활용)

```
[자산 1]: ____
  - 효과: ____
  - 청중 반응 수치: ___ / 10
  - 재활용 방식: ____

[자산 2]: ____
  - 효과: ____
  ...
```

### C.2 PROBLEM — 식별된 문제

```
[문제 1]: ____
  - 영향도: 🔴 high / 🟡 medium / 🟢 low
  - 관련 슬라이드/메시지: ____
  - 발생 빈도: 1회성 / 반복 가능
  - 청중 점수 영향: ___ 점 (예: -2점 in 메시지 명확성)

[문제 2]: ____
  ...
```

### C.3 TRY — 다음 시연에서 시도할 것

```
[시도 1]: ____
  - 기대 효과: ____
  - 관련 PROBLEM ID: ___
  - 준비 시간 추정: ___ 시간/일

[시도 2]: ____
  ...
```

### C.4 KPT 통합 표 예시

| 분류 | 항목 | 우선순위 | D+7 액션 |
|---|---|---|---|
| KEEP | Slide 3 8 WS 대시보드 (가장 강력) | ⭐⭐⭐ | 다음에도 핵심 위치 유지 |
| KEEP | Slide 4 Phase B vs C 비교 | ⭐⭐⭐ | 다음에는 비교 prefer 유지 |
| KEEP | Cheat sheet 60초 답변 | ⭐⭐ | 다음 시연도 동일 패턴 |
| PROBLEM | Slide 3 timing 7분 → 8분 30초 (시간 초과) | 🔴 high | 슬라이드 분할 또는 ⑥⑦⑧ 압축 |
| PROBLEM | Q3 손실확률 답변 시 추가 설명 요청 | 🟡 medium | Q3 답변에 시각화 자료 첨부 |
| PROBLEM | 카니발 매트릭스 산식 (3-4명 어려워함) | 🟡 medium | 비유 1-2개 추가 (예: "포트폴리오 = 한 가족의 지갑") |
| TRY | Live Demo 옵션 사전 시연 | ⭐ | 다음 시연 시 청중에 따라 전환 |
| TRY | 실제 dashboard 스크린샷 1장 슬라이드 3에 추가 | ⭐⭐ | D+5까지 캡처 + 슬라이드 갱신 |
| TRY | Q11 (sparse) 답변 보강 (실제 페어 9개 visualization) | ⭐ | 다음 시연용 부록 슬라이드 추가 |

### E.2 Phase v3 trigger 의사결정 매트릭스

| 신호 | 추진 GO 신호 | 보류 NO-GO 신호 |
|---|---|---|
| 전체 만족도 | ≥ 7/10 | ≤ 5/10 |
| 도입 시점 의향 | 즉시 + 다음 분기 ≥ 60% | 추가 검토 필요 ≥ 50% |
| Phase v3 우선순위 명시 | 응답자 ≥ 5명 일치 | 응답자 의견 분산 |
| ROI 인식 | "단년 회수" 동의 | "ROI 불명확" 다수 |

→ **3개 이상 GO 신호** → Phase v3 시작 (2026-Q3)
→ **3개 이상 NO-GO 신호** → 현 도구 운영 안정화 우선 (Phase v3 2026-Q4 또는 2027 이연)
