# Phase C 통합 시연 — 6 WS 종합 의사결정 Case Study

**대상**: 경영진 · 영업본부장 · 재무·전략 의사결정자
**소요**: 약 15-20분 (단일 case 종합 분석)
**핵심 메시지**: "**McKinsey 95% 프레임워크가 단일 의사결정에 동시 작동하는 모습**을 한 사례로 시연"
**작성일**: 2026-04-27 (Phase v3 진입 직전)
**D-5 dry-run 반영**: 2026-04-27 (Top 15 가중평균 영업이익률 9.6% 실측 반영)

---

## 🎯 1줄 요약 (Conclusion First)

> Phase C 완료로 저가수주 판단기는 **단일 결정 → 시장 반응 → 시간 차원 → 포트폴리오 순효과 → 확률 → LTV** 6 축 동시 분석이 1화면에서 가능. 같은 사안을 Phase B로 판단했다면 **+6,800만 GO**, Phase C로는 **+4,000만 조건부 GO** — 동일 사안, 의사결정 정밀도 ±2,800만 차이.

## 0. Case 배경 (Situation)

| 항목 | 내용 |
|---|---|
| **시점** | 2026-Q2 (현재) |
| **고객** | 대한건설 (가칭, 인프라 본부 누적 매출 비중 8% 핵심 거래처) |
| **거래처 분류** | 주력 (장기·고매출·신용양호) |
| **품목** | 우레탄 단열재 P-2024 (옥천 공장 생산) |
| **품목 분류** | 단열재 대분류 / 우레탄 중분류 |
| **현행 거래** | 25,000 BAG/년, 80,000원/BAG, 매출 20억 |
| **단위 마진** | 12,000원/BAG (15%, 변동비 68,000원) |
| **공장 가동률** | 옥천 라인 1: **87%** (잔여 capacity 3,900 BAG/월) |

### 협상 요청 (Complication)

대한건설 구매팀이 다음 조건 제안:
- **단가**: 80,000원 → **73,600원** (-8% 인하)
- **물량**: 25,000 → **37,500 BAG** (+50% 증가, 6개월 약속)
- **지속 기간**: 6개월 (이후 재협상)
- **암묵적 신호**: B 사 P-1024 견적이 더 유리하다는 언급 (경쟁사 압박)

### 영업현장의 단순 판단 (Problem)

김 과장의 첫 직감 계산:
```
단가 -8% × 25,000 BAG = -1,600만 손실
물량 +50% × (12,000 - 6,400) = +6,800만 이익  
                              ────────
                              순+6,800만? 박리다매 GO!
```

**하지만 이 판정은 6개 차원의 다른 변수를 무시하고 있습니다.**

## 2. WS2 공학적 제약 (Phase A — Capacity)

물량 +50%(12,500 BAG) 추가가 옥천 라인 capacity 안에서 가능한지 확인합니다.

```
현행: 25,000 BAG/년 = 2,083 BAG/월
필요: 37,500 BAG/년 = 3,125 BAG/월
캐파: 옥천 라인 1 = 3,900 BAG/월 (잔여 1,817)
```

| 시나리오 | 가동률 | 판정 |
|---|---|---|
| 25% 증가만 (31,250) | 약 87 → 95% | 🟡 caution |
| **50% 증가 (37,500)** | **약 87 → 110%** | 🚨 **severe — 신규 라인 또는 외주 필요** |
| 외주 시 단위 변동비 | +5,000원/BAG | 추가 변동비 발생 |

🔴 **첫 적신호**: capacity 110% — 약 1,250 BAG/월(15%)이 외주로. **변동비가 +5,000원/BAG 증가하여 단위공헌이익이 5,600 → 600원**으로 추락할 위험.

## 3. WS4 PED — 가격 탄력성 (Phase B 자산)

자연 수요 반응을 추정합니다 (강제 약속이 아닌 자유 시장 반응).

| 지표 | 값 |
|---|---|
| P-2024 추정 PED | -1.2 (R² 0.71, n=14M, 신뢰도 high) |
| 산업 폴백 (단열재) | -1.0 |
| -8% 인하 시 자연 수량 변화 | (1+0.08)^1.2 ≈ +9.7% |

🟡 **자연 수요는 +9.7%**인데 고객은 +50%를 약속함. 차이 **+40.3%포인트는 강제 발주** = 다음 6M 후 정상화 시 **재고 누적 / 반품 위험**. 박리다매의 표면 +50%는 거짓 신호.

## 4. WS5 LTV — 거래처 평생 가치 (Phase B 자산)

거래처 가치를 의사결정에 가산합니다.

| 지표 | 값 |
|---|---|
| 대한건설 LTV (12M Forward) | **8억 4,000만원** |
| Churn 위험 (수용 시) | 5% (안정 유지) |
| Churn 위험 (거절 시) | **35%** (B 사 전환 위협) |
| LTV 차이 (수용 시 − 거절 시) | +30%p × 8.4억 = **+2억 5,200만원** |

🟢 **거래처 유지 가치는 큼** — 수용 시 LTV +2억 5천 보전. 거절 시 다른 품목 매출까지 잠재적 손실. **수용 측 강한 유인**.

## 5. WS1 Monte Carlo — 확률 기반 95% CI (Phase A 자산)

점추정 +6,800만이 얼마나 신뢰할만한지 확률 분포로 변환합니다.

| 시뮬 (10,000 회) | 값 |
|---|---|
| 평균 영업이익 변화 | +6,000만원 (점추정 +6,800만보다 -800만 낮음, 비대칭 분포) |
| **95% CI** | **-1,800만 ~ +12,300만** (폭 14,100만) |
| **손실확률** | **22%** (5번 중 1번 이상 적자) |
| 최악 5% (P5) | -3,400만 |

🟠 **점추정의 함정 노출** — 평균이 +5,200만이지만 **CI 폭이 매우 넓음**. 경영진 결정 시 손실확률 22%는 명시적으로 인지해야 함.

## 6. WS6 경쟁사 반응 시나리오 (Phase C — 신규)

**여기서부터 Phase C가 추가한 차원입니다.**

대한건설이 우리에게 -8% 받았다면, **B 사도 다른 거래처에 -8% 제안 가능성** 있습니다.

| 시나리오 | 시장 평균가 | 자사 점유율 변화 | 자사 매출 변화 |
|---|---|---|---|
| 단독 (R=0%) | 80,000 → 80,000 | 30% → 31% (+1%p) | +50% (협상대로) |
| **50% 보복 (R=50%)** | 80,000 → 76,800 | 30% → 30.5% | **+38%** (점유율 일부 흡수 약화) |
| **100% 보복 (R=100%)** | 80,000 → 73,600 | 30% → 30% (변동 없음) | **+10%** (시장 평균가 동일, 단순 PED만 작용) |

🟠 **보복 시나리오의 충격**: 100% 보복 시 우리 매출 증가는 +50% → +10%로 추락. **점유율 우위가 사라지고 단순 가격 인하 손실만 남음**.

## 7. WS7 12개월 시간 차원 (Phase C — 신규)

6M 약속 이후 시점까지 포함한 12M 누적 분석.

| M1 | M3 | M6 | M9 | M12 |
|---|---|---|---|---|
| -1,200만 | -800만 | **+200만 (BEP 도달)** | +1,800만 | +3,400만 (NPV) |

| 가정 | 값 |
|---|---|
| 학습률 | 0.90 (보수적) — 누적 2배 시 단위VC -10% |
| 원가 lag | 3M (원자재 인상 6M 후 단가 반영) |
| NPV 할인율 | 월 0.5% (연 6%) |
| 계절성 | 7-8월 비수기 -15%, 11-12월 성수기 +20% |
| **12M NPV** | **+3,400만원** |
| **BEP** | M6 (협상 종료 시점) |

🟢 **시간 차원 유리** — 학습곡선과 원가 lag가 협상 후반 흑자 전환 견인. **하지만 BEP가 정확히 협상 종료 시점**이라는 점은 위험 — 7M 이후 정상화 안 되면 누적 흑자 미실현.

## 8. WS8 카니발라이제이션 (Phase C — 신규, 마지막 자산)

**P-2024 매출이 50% 증가하면 우리 회사 다른 품목 매출은?**

대한건설은 우리 회사 단열재 + 방수재를 모두 구매. 카니발 매트릭스에서:

| 잠식 품목 | 카니발 계수 c | 잠식 손실 (6M 기준) |
|---|---|---|
| **P-2025 (PU 발포제 형 변형품, 같은 대분류)** | 0.45 (high) | **-2,800만원** |
| **Q-3022 (방수재, 다른 카테고리)** | 0.18 (medium) | -1,100만원 |
| Q-2030 PE 단열재 | 0.32 (medium) | -1,500만원 |
| 기타 품목 | 합계 | -1,000만원 |
| **자기잠식 합계** | — | **-6,400만원** |

🔴 **자기잠식의 충격** — 매출 잠식 합계 -6,400만이 같은 회사 다른 품목에서 새어 나감. 영업이익율 10% (D-5 실측) 환산 시 영업이익 영향 **-700만**. 단독효과만 보면 +6,800만 GO 결정이 합리적이나 *포트폴리오 잠식·경쟁사 보복·12M NPV* 동시 차감 시 **+4,000만 조건부 GO**로 정밀화.

### 종합 영업이익 (Phase C 정밀 계산 — D-5 dry-run 반영)

```
김 과장 단순 판단:                        +6,800만원
└─ 일견 박리다매 성공 (Phase B 자산 미반영 표면값)

WS3 베이스라인 보정:                      ± 0 (단위공헌이익 양수 유지)
WS2 capacity outsource:           -1,500만 (외주 추가 변동비, 6M 기준)
WS4 PED 자연 수량 한계:                  -100만 (강제발주 반품 6M 영향)
WS5 LTV 거래처 가치 (6M 환산):     +2,400만 (수용 vs 거절 차이의 6M 영업이익 영향)
WS1 Monte Carlo 평균:                -800만 (점추정 +6,800 → 평균 +6,000)

── Phase B 자산 적용 후 소계: ─────────────  +6,800만 (Phase B 시점 결론)

WS6 경쟁사 50% 보복 가정:          -800만 (시장 균형 효과)
WS7 12M NPV - 단순합 차이:        -1,300만 (할인 + 시간 시차 효과)
WS8 카니발 (영업이익 환산):         -700만 (매출 잠식 -6,400만 × 영업이익율 10%)

── Phase C 자산 추가 차감: ────────────────  -2,800만 (Phase C 추가 정밀화)
                                  ────────
                              합계 +4,000만원 ± 14,100만 (95% CI)
                              손실확률 22%, BEP M6 (slim)
```

**수치 구분 주의 (D-5 dry-run 반영, 2026-04-27 갱신)**:
- WS5 LTV의 *전체 12M 보전 효과 +2.5억(25,200만)*은 거래처 churn 회피 가치 — 이 case의 6M 영업이익 영향 환산은 +2,400만 (보전 효과의 일부 반영)
- WS8 *매출 잠식 -6,400만*은 동일 거래처 다른 품목 (보완재/대체재) 6M 매출 감소량 — sales-level dramatic 표시
- WS8 *영업이익 환산 -700만*은 위 매출 잠식의 회사 전체 영업이익 영향 (D-5 실측: 인프라 본부 Top 15 가중평균 영업이익율 **9.6%** 적용)
- 초기 case study에서 영업이익율 36% 가정으로 -2,300만 환산했으나 실측 데이터(석유화학 위주, margin 10% 수준) 반영 시 -700만이 더 정확
- Phase B 자산 적용 시 capacity/PED/MC 부정적 효과를 LTV가 거의 정확히 상쇄하여 Phase B 시점 결론은 단순 판단과 동일한 +6,800 (우연의 일치적 cancel-out — 핵심 거래처 LTV 가치가 컸기 때문)
- 본 case study의 +4,000만 합계는 영업이익 기준 — 매출 기준 환산 시 약 +4억 (영업이익율 10% 역산)

| WS6 시장 보복 | 시장 균형 흔들림 | **단가 표시 가격 유지 + 거래처별 할인 (BAG당 6,400원)**: 시장가 노출 차단 |
| WS7 BEP M6 | 협상 종료 시점 일치 위험 | **6M 후 자동 갱신 옵션** 명문화 |
| WS8 카니발 -6,400만 | 자기잠식 큼 | **P-2025 등 잠식 품목 동시 인상 1-2% 시도** (포트폴리오 보전) |

위 5개 조건이 협상에서 절반만 받아들여도 순효과는 **+4,000만 → +5,500만+**까지 향상.
