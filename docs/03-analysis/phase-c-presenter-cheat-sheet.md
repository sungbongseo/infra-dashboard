## 🎯 핵심 메시지 (시연 중 3회 반복 권장)

> **"+6,800만 GO → +4,000만 조건부 GO. -2,800만의 보이지 않던 위험을 알고 결정합니다."**

**사실 카드** (외워둘 5가지):
- ① 영업이익 단순 +6,800만 → Phase C 종합 +4,000만
- ② Phase C 정밀화 -2,800만 (WS6 -800 + WS7 -1,300 + WS8 -700)
- ③ 손실확률 22%, 95% CI ±14,100만, BEP M6
- ④ McKinsey E축 50→85% (+35%p), 전체 95% 도달
- ⑤ 5개 협상 조건 절반 수용 시 +5,500만+

## 📋 Q&A 11 답변 (1줄 핵심 + 60초 풀 답변)

### Q1. 카니발 매트릭스 신뢰도?

🎯 **1줄**: "14M Pearson, 신뢰도 high/medium/low 자동 분류, 상관 ≠ 인과 명시"

📝 **풀**: 14M 데이터 기반 Pearson 상관, 신뢰도 high/medium/low 자동 분류 (샘플 ≥4M 필터). "상관 ≠ 인과" UI 명시. 영업 현장 검증으로 Top 잠식 = 같은 카테고리 직관 일치 확인.

### Q2. -8% 거절하면 거래처 이탈?

🎯 **1줄**: "WS5 LTV churn 35% (수용 5%), 보전 +2.5억, 5조건으로 위험 낮춤"

📝 **풀**: WS5 LTV 모델에서 거절 시 churn 35% (수용 시 5%) 추정. 거래처 보전 +2.5억은 충분 인정. 5개 조건 협상으로 이탈 위험 낮추면서 자체 손실 최소화 가능.

### Q3. 손실확률 22% 너무 높지 않나?

🎯 **1줄**: "평균 +6,000만, 5번 중 1번 적자 가능. 모르고 GO는 위험, 알고 GO는 합리적"

📝 **풀**: 점추정 +6,800만이 가짜 확신. 실제는 평균 +6,000만이고 5번 중 1번 적자 가능 (95% CI -1,800~+12,300만). 명시 없이는 5번째 사례에서 책임 소재. 22% 명시 인지 후 수용은 합리적.

### Q4. Phase v3 시작 시기?

🎯 **1줄**: "2026-Q3 시작, 우선 자산: LP 동적 가격 엔진 (+600 LOC, 6-7월)"

📝 **풀**: 2026-Q3 시작 권장. 우선 자산: 카니발 매트릭스 → LP 동적 가격 엔진 (+600 LOC, 6-7월 예상). 외부 데이터 결합 (산업 PED, 경쟁사 동향)은 2027 진입.

### Q5. 본 case study 실제 거래처 적용?

🎯 **1줄**: "Illustrative이며 dashboard 분 단위 정밀 재계산 가능"

📝 **풀**: 본 case는 illustrative 시연 목적. 실제 거래처 P-2024 등이 있다면 그 데이터로 정밀 재계산 권장. 본 시스템은 같은 분석 흐름을 분 단위로 적용 가능.

### Q6. 14M 데이터 충분성? Phase v3 24M 시 결과 변화?

🎯 **1줄**: "방향성 정확, 정확한 강도는 v3 24M 누적 시 정밀화"

📝 **풀**: 샘플 ≥4M 필터 + 신뢰도 high/medium/low 자동 분류로 방향성 정확. 24M 누적 시 (1) 신뢰도 등급 상향, (2) 계수 안정화 (계절성 2 사이클), (3) 동적 학습으로 시간별 c 변화 포착. 정확한 강도는 v3에서 정밀화.

### Q7. 5개 협상 조건 거절 시 손실?

🎯 **1줄**: "부분 수용 (3/5)이 현실적 — +4,000만 baseline 보전, 거래처 이탈은 별도 이슈"

📝 **풀**: 부분 수용 (3/5) 현실적: +4,000만 → 약 4,500만 (보수적 기대값). 완전 거절 시도 baseline +4,000만 보전. 거래처 이탈은 5조건 협상이 원인이 아닌 단가 양보 거절의 결과 — 별도 LTV 영향 -2.5억.

### Q8. AI 자동화 시 영업담당 역할? 인력 영향?

🎯 **1줄**: "Augment NOT replace, 분석 -90% 시간 → 미팅·전략 +50% 시간"

📝 **풀**: Phase v3는 automation NOT replacement. AI는 8축 분석 자동화 (15-20분 → 1-2분), 인간은 거래처 관계·전략·실제 협상에 집중. 시간 재분배: 분석 -90%, 미팅·전략 +50%. 신입 onboarding 50% 단축. **영업 능력 증강, 대체 아님**.

### Q9. ROI 정량화?

🎯 **1줄**: "연 50건 × ±2,800만 = ±14억 의사결정 정밀도, 단년 회수"

📝 **풀**: 인프라 본부 연 50건 협상 × ±2,800만 정밀화 = 연 ±14억 의사결정 정밀도. 보수적 5% 흡수 시 연 7,000만 손실 회피. 개발 투자 (Phase A+B+C 누적 약 6주 인력) 대비 단년 회수. Phase v3 자동화 시 ROI 추가 향상.

### Q10. 다른 본부·계열사·외부 회사 이식 가능?

🎯 **1줄**: "Universal framework, 동일 본부 즉시 / 외부 3-6개월"

📝 **풀**: 8 WS 모두 산업 무관 universal framework. 동일 사업본부 schema (100·200 등): 즉시 적용. 다른 본부 (화학·전자): 1-2개월 (schema 매핑). 계열사: 2-3개월. 외부 회사 (라이선스): 3-6개월. **B2B 의사결정 정밀화의 universal 자산**.

### Q11. 카니발 매트릭스 페어 9개 너무 적지 않나?

🎯 **1줄**: "거래처 집중 거래 패턴 — 본 사업본부 특성 반영 보수적 추정, v3에서 풍부화"

📝 **풀**: 거래처가 Top-15 제품 중 1-2개에 집중 거래하는 패턴 때문. 즉 -700만 잠식은 본 사업본부 특성에 비례한 보수적 추정. Phase v3에서 (1) 전 품목 분석 (2) 24M 누적 (3) 집중도 가중으로 매트릭스 풍부화 가능.
