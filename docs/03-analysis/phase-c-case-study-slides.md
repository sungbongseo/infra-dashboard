# Slide 2 — Case 배경

## 대한건설 우레탄 단열재 P-2024 협상

### Situation
- 거래처: **대한건설** (인프라 본부 매출 비중 8% 핵심)
- 품목: **우레탄 단열재 P-2024** (옥천 공장)
- 현행: 25,000 BAG/년, 80,000원, **단위공헌이익 12,000원 (15%)**
- 공장 가동률: **87%**

### 협상 요청 (Complication)
| 차원 | 요청 |
|---|---|
| 단가 | -8% (80,000 → 73,600원) |
| 물량 | **+50% (25K → 37.5K BAG)** |
| 약속 | 6개월 |
| 압박 | 경쟁사 B 사 P-1024 견적 언급 |

### 영업 직감 판단 (Problem)

> "단가 -8% × 25K = -1,600만 / 물량 +50% × 5,600 = +6,800만 → **박리다매 GO!**"

<div class="amber">⚠ 6개 다른 차원 무시 — 의사결정의 함정</div>

# 부록 — Q&A 대응 메모

### 자주 받는 질문 + 답변

**Q1. 카니발 매트릭스의 신뢰도는?**
A. 14M 데이터 기반 Pearson 상관, 신뢰도 high/medium/low 자동 분류 (샘플 ≥4M 필터). "상관 ≠ 인과" UI 명시. 영업 현장 검증으로 Top 잠식 = 같은 카테고리 직관 일치 확인.

**Q2. -8% 인하를 거절하면 거래처 이탈?**
A. WS5 LTV 모델에서 거절 시 churn 35% (수용 시 5%) 추정. **거래처 보전 +2.5억은 충분히 인정**. 단, 5개 조건 협상으로 이탈 위험 낮추면서 자체 손실도 최소화 가능.

**Q3. 손실확률 22%는 너무 높지 않나?**
A. 점추정 +6,800만이 가짜 확신. 실제는 평균 +6,000만이고 5번 중 1번은 적자 가능 (95% CI -1,800~+12,300만). **이를 명시하지 않으면 5번째 사례에서 책임 소재 발생**. 22%를 명시 인지 후 수용은 합리적, 모르고 수용은 위험.

**Q4. Phase v3는 언제 시작?**
A. 2026-Q3 시작 권장. 우선 자산: 카니발 매트릭스 → LP 동적 가격 엔진 (+600 LOC, 6-7월 예상). 외부 데이터 결합은 2027 진입.

**Q5. 본 case study가 현재 실제 거래처에 적용 가능?**
A. Illustrative이며 시연 목적. 실제 거래처 P-2024가 있다면 그 데이터로 정밀 재계산 권장. 본 시스템은 같은 분석 흐름을 분 단위로 적용 가능.

**Q6. 14M 데이터로 충분한가? Phase v3 (24M) 시 결과 변화 가능성?**
A. 샘플 ≥4M 필터 + 신뢰도 high/medium/low 자동 분류로 **방향성은 정확**. 24M 누적 시 (1) 신뢰도 등급 상향, (2) 계수 안정화 (계절성 2 사이클), (3) 동적 학습으로 시간별 c 변화 포착. 정확한 강도는 v3에서 정밀화.

**Q7. 5개 협상 조건 모두 거절될 경우 손실은?**
A. 부분 수용 (3/5)이 현실적: +4,000만 (보수적 기대값). 완전 거절 시도 baseline +4,000만 보전. 거래처 이탈은 5조건 협상이 원인이 아닌 단가 양보 거절의 결과 — 별도 LTV 영향 -2.5억 (수용 시 회피).

**Q8. AI 자동화 시 영업담당 역할? 인력 영향?**
A. Phase v3는 **automation NOT replacement**. AI는 8축 분석 자동화 (15-20분 → 1-2분), 인간은 거래처 관계·전략·실제 협상에 집중. 시간 재분배: 분석 -90%, 미팅·전략 +50%. 신입 onboarding 50% 단축. **영업 능력 증강, 대체 아님**.

**Q9. 본 시스템 ROI 정량화 가능?**
A. 인프라 본부 연 50건 협상 × ±2,800만 정밀화 = **연 ±22억 의사결정 정밀도**. 보수적 5% 흡수 시 연 **1.1억 손실 회피**. 개발 투자 (Phase A+B+C 누적 약 6주 인력) 대비 단년 회수. Phase v3 자동화 시 ROI 추가 향상.

**Q10. 다른 사업본부·계열사·외부 회사 이식 가능?**
A. 8 WS 모두 **산업 무관 universal framework**. 동일 사업본부 schema (100·200 등): **즉시 적용**. 다른 본부 (화학·전자): 1-2개월 (schema 매핑). 계열사: 2-3개월. 외부 회사 (라이선스): 3-6개월. **B2B 의사결정 정밀화의 universal 자산** — Phase v3 도달 시 외부 라이선스 검토 가능.
