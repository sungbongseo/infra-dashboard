## 6. Lessons Learned & Retrospective

### 6.1 What Went Well (Keep)

- **병렬 에이전트 실행**: 3개 에이전트 동시 실행으로 1일 완성 가능 (기존 3~4일)
  → 향후 복잡도 높은 기능은 에이전트 병렬화로 속도 향상

- **설계 기반 구현**: 선행 설계(Plan/Design)가 구현 정확도를 100%로 끌어올림
  → 21개 모두 설계 부합 달성, 재작업 0건

- **자동 인사이트 엔진**: insightGenerator.ts 모듈화로 새 인사이트 추가 용이
  → 향후 KPI/경고 추가 시 기존 모듈 재활용 가능

- **점증적 개선**: 4 Phase 구조(표시→인사이트→전략→교차)로 복잡도 점진적 증가
  → 단계별 검증으로 리스크 최소화

### 6.2 What Needs Improvement (Problem)

- **HHI 계산 복잡도**: 거래처 집중도 지수는 도메인 지식 필요
  → 향후 도메인 전문가 검증 권장

- **BCG/4사분면 라벨 자동화 미흡**: 임계값 기반 자동분류 시 경계 케이스 발생
  → 임계값 튜닝 문서 작성 필요

- **RFM 세그먼트 기준**: 5점 만점 기준이 산업별로 다를 수 있음
  → 설정가능한 임계값으로 변경 권장

### 6.3 What to Try Next (Try)

- **대시보드 실시간 성과 모니터링**: 자동 인사이트 정확도 추적용 분석 대시보드
  → 사용자 반응/실제 액션 데이터 수집

- **사용자 피드백 루프**: A/B 테스트로 라벨, 경고, 색상 효율성 검증
  → 데이터 기반 UI 최적화

- **다국어 인사이트**: 한국어 제한에서 영어/중국어 자동 생성
  → 글로벌 확장 시 즉시 대응

- **고급 머신러닝 모델**: 이상치 탐지, 이탈 예측을 ML 모델로 고도화
  → 통계기반(IQR) → ML기반 전환
