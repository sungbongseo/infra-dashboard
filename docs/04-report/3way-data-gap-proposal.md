## 3. 장기 조치 (사용자/조직 액션 필요)

### 3.1 Critical: 울산·용산 표준원가 엑셀 추가 업로드

**요청 대상**: 원가회계팀 (또는 생산관리팀)

**필요 파일**:
- `울산공장 표준원가 3월31일 기준.xlsx` — 울산 398개 제조 품목의 표준원가
- `용산본사(석유) 표준원가 3월31일 기준.xlsx` — 경유·등유 등 석유제품

**파일 스키마**: 기존 양산/청산 파일과 동일 (9 컬럼: No, 품목코드, 품목명, 품목계정그룹, 기본단위, 규격, 표준원가, 시작일, 종료일)

**예상 효과**:
| 지표 | 현재 | 울산 추가 후 | 용산 추가 후 | 둘 다 추가 |
|---|---:|---:|---:|---:|
| 표준원가 매칭 커버리지 | 85건 | +≈60건 | +≈5건 | **+65건** |
| 3-Way 완전 매칭 | 36 (19%) | ≈85 (45%) | ≈40 (21%) | **≈100 (52%)** |
| 추가 커버 매출 | — | 소규모 | **+5.6억원** (석유) | **5.6억+** |

### 3.2 High: 제조원가 고정비 분배 검토

**현재 상태**: Parser가 고정비 0인 생산품 비율을 warning으로 발행. 샘플 검증 결과 일부 품목 (예: RA7 콤파운드 MPRP6281101)에서 고정비 0 확인.

**원인 후보**:
1. BOM 자식 행에만 일부 비용이 분배되고 Header 행(수량 보유 행)에는 고정비 미기재
2. 공통 고정비가 원가계산 마감 전이라 아직 분배 안 됨
3. 해당 품목이 R&D/샘플 생산이라 고정비 제외 정책

**필요 확인**:
- 원가회계팀에 "고정비 0 품목 리스트"(warning에서 자동 출력) 공유 → 분배 누락인지 정책인지 명확화
- 공통 고정비 배부 완료된 재업로드 파일 요청

**영향**: 고정비가 분배되지 않으면 `actualUnitCost`가 **변동비만으로 구성** → 실제보다 저렴하게 산출되고, 표준원가 대비 비교 시 "더 저렴하게 제조된 것처럼" 잘못된 양성 결론 발생.

### 3.3 Medium: 품목명 표기 표준화

현재 발견된 표기 차이 패턴:
- `AP-5 /BULK(상품)` vs `AP-5/BULK` — 괄호 접미사 + 슬래시 공백
- `RA7 콤파운드(침적)` vs `RA7 콤파운드` — 괄호 용도 표시

**제안**: SAP 마스터 데이터 레벨에서 품목명을 규격화. 또는 판매사업부 레벨에서 100 보고서 추출 시 괄호 접미사 제거 SOP 적용.

## 4. 검증 절차 (후속 업로드 시)

1. 용산/울산 표준원가 엑셀 수령 → 대시보드 업로드
2. **원가 분석 > 3-Way** 탭 진입 → "공장별 표준원가 커버리지" 카드가 모두 100%로 전환됐는지 확인
3. Step 1 coverage KPI에서 "3-Way 매칭" 숫자가 36 → 100+로 증가했는지 확인
4. Step 6 표준원가 정확도 KPI 등급이 갱신됐는지 확인
5. Step 9 "미매칭/미등록" 섹션에서 "경유/bulk" 등 용산 품목이 사라졌는지 확인
