## 2. 실제원가 커버리지 정밀 분류

### 2.1 개선 전후 비교

| 분류 | 개선 전 | 개선 후 | 해석 |
|---|---:|---:|---|
| **3-Way 완전 매칭** | 37 | 37 | 제조원가 BOM 기반 (자체 제조) |
| **상품 (매입가 적용)** | 0 (누락 표시) | **78** | 표준원가 = 매입가 — **실제원가 있음** |
| **제품 미생산** | (구분 불가) | **12** | Q1 BOM 없음 — **원가팀 확인 필요** |
| **표준 미등록** | (구분 불가) | 0 | 4개 표준원가 파일로 모두 커버 |
| **매핑 실패** | (구분 불가) | **7** | 표준원가 신규 등록 필요 |
| **합계** | 134 | 134 | |
| **실제원가 산출 가능** | 37 (28%) | **115 (86%)** | **+58%p** |
| **액션 필요** | 불명확 | **19 (14%)** | 명확한 액션 리스트 |

### 2.2 핵심 인사이트

기존 시스템은 "제조원가 없음"을 모두 누락으로 표시 → 상품(매입품) 78건도 경고로 분류되어 사용자 혼란. 실제로는:

- **상품(78건)**: 외주 매입품으로 제조하지 않음 → 표준원가 = 매입 단가 → **실제원가 이미 존재**
- **제품(12건)**: 자체 제조해야 하는데 Q1에 미생산 → 진짜 누락
- **매핑 실패(7건)**: 표준원가 book에 아예 없음 → 신규 등록 필요

## 6. 예상 효과

### 사용자 관점
- 대시보드 KPI에서 "실제원가 산출 완료 115건 (86%)"이 명확히 표시
- "원가팀 확인 필요 19건"이 별도 섹션으로 분리 — 즉시 액션 가능
- "Black Top Sheet(1.0mm*20m)_옥천" 같은 사용자 예시가 이 섹션에 자동 포함

### 원가팀 관점
- 엑셀 추출 버튼 없이도 화면에서 12+7건 리스트 즉시 확인 가능
- 매출공장 vs 표준원가공장 불일치도 명시 (예: 아스본드 청산 vs 울산)

### 재무 관점
- 실제원가 커버리지 28% → 86%로 향상 → 수익성 분석 신뢰도 향상
- 상품 78건(124M원)이 "누락"에서 "매입원가 적용"으로 재분류 → **실제로는 기존에 정상 산출 가능했던 데이터가 UI에서만 누락으로 보였던 것**

## 7. 후속 제안

### 7.1 단기 (원가팀 협의 후)
- 제품 12건 BOM 추가 업로드 → 3-Way 매칭 37 → ~49건 예상

### 7.3 장기
- SAP 품목 마스터에서 품목명 표기 표준화 (괄호/공백/슬래시 불일치 SOP)
