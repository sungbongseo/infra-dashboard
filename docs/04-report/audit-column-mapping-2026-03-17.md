## H-01 [High] 303/304/401 미할당 조직 매출 누락

**파일**: `src/lib/excel/parser.ts` lines 483-519
**영향 범위**: Overview 총 매출, 조직별 손익 비교

### 문제
303(조직별손익II), 304(조직별거래처별), 401(팀원별공헌이익) 파일의 Row 2에는 조직명이 비어있지만 실적 데이터가 있는 행이 존재합니다. 이 행은 `if (!org) throw new Error("SKIP_ROW")`에 의해 올바르게 건너뛰어지지만, 해당 매출이 어디에도 반영되지 않습니다.

### 검증 데이터 (303, 202602 시트)

| 행 | 조직 | 매출 실적 | 처리 |
|----|------|-----------|------|
| Row 2 | (비어있음) | 391,295,278 | SKIP_ROW → 누락 |
| Row 23 | (비어있음) | 115,696,415 | SKIP_ROW → 누락 |
| 합계 행 | 합계 | 22,099,089,145 | SKIP_ROW |
| 개별 조직 합 | - | 21,592,097,452 | 파서 결과 |
| **차이** | - | **506,991,693 (2.3%)** | 누락 |

### 영향
- 대시보드의 조직별 매출 합계가 엑셀 합계 행보다 ~2.3% 적게 표시됨
- 이 차이는 미할당 조직 또는 전사 공통 매출일 수 있음

### 수정 권고
1. 조직명이 비어있는 행을 "(미배분)" 조직으로 분류하여 별도 표시
2. 또는 합계 행과의 차이를 경고 메시지로 표시

## M-01 [Medium] 매출리스트 품목범주 필드명 불일치

**파일**: `src/lib/excel/parser.ts` line 412
**영향 범위**: 품목범주 기반 분석

### 문제
파서가 `품목범주: str(row[45])`로 읽지만, 실제 엑셀 col 45는 `품목제품군`입니다. `품목범주`는 col 41에 있습니다.

```
실제 엑셀:
  col 41: 품목범주
  col 45: 품목제품군

파서 매핑:
  품목범주: str(row[45])  ← 실제로는 품목제품군 값을 읽음
```

### 수정
```typescript
품목범주: str(row[41]),    // was row[45]
품목제품군: str(row[45]),  // 별도 필드로 분리
```

## M-02 [Medium] 100 파일 초반 빈 조직 행의 역방향 fill-down 오염

**영향 범위**: 거래처별 품목별 손익 데이터 일부 오염

### 문제
100(거래처별,품목별 손익) 파일의 상위 ~278행은 조직/거래처가 비어있지만 품목명이 있는 행입니다. `fillDownMultiLevel`의 역방향 패스에서 이 행들의 `영업조직팀`이 첫 번째 유효 조직(EC사업팀)으로 채워집니다.
